UniFi Alarm Manager

Lagre alle skilt

0 av 4 signaler verifisertReglene testes automatisk når første lokale webhook kommer inn.
Venter
  1. Opprett én alarm for License plate · Known og én for License plate · Unknown.
  2. Velg handlingen Webhook / HTTP POST og bruk adressen under.
  3. Velg HTTP POST. Gateway-adressen 192.168.1.1 er godkjent lokalt, så Protect trenger ikke støtte egendefinerte POST-headere.
  4. Gjenta for Face · Known og Face · Unknown hvis ansikter skal lagres.
/api/v1/webhooks/unifi-alarm

Protect utfører selve gjenkjenningen lokalt. Andre avsendere må bruke webhook-token som Bearer, X-API-Key eller ?token=…. Ledger lagrer verdien UniFi sender, rå webhook og kobling til nærmeste hendelse/stillbilde. UniFis støttede API kan ikke opprette Alarm Manager-regler; de fire valgene må derfor gjøres én gang i Protect-grensesnittet.
